# P4-05: Episode builder

- **Phase:** P4
- **Model:** sonnet
- **Deps:** P4-01
- **Size:** ~100 lines

## Goal
Merge a stock's flagged days into episodes, so the output reads "stock X, episode from date A to date B" instead of 30 separate alerts (PLAN.md 3.3, step 5). This chunk does gap-based merging. Change-point refinement is a later chunk if evaluation shows it is needed.

## Files
- `src/saham_gorengan/detectors/episodes.py` (new)
- `tests/test_detectors_episodes.py` (new)

## Interface
```python
def build_episodes(ranks: pd.DataFrame, k: int = 25, max_gap: int = 3, min_flags: int = 1) -> pd.DataFrame: ...
    """ranks: date, ticker, rank (Int64; NA = unranked). Output, one row per episode:
    episode_id (string), ticker (string), start, end (datetime64[ns]), n_flag_days (Int64), best_rank (Int64)."""
```

## Behaviour
- Trading days are the sorted unique dates in `ranks`. A row is **flagged** when `rank <= k`; NA is not flagged.
- For each ticker, walk its flagged days in date order. Start a new episode when the number of trading days strictly between the previous flagged day and this one is greater than `max_gap`.
- `start` and `end` are the first and last flagged days. `n_flag_days` counts flagged days and `best_rank` is the minimum rank in the episode.
- Drop episodes with `n_flag_days < min_flags`. `episode_id = f"{ticker}-{start:%Y%m%d}"`.
- Output is sorted by (start, ticker) with a fresh RangeIndex. Empty input, or no flags, gives an empty frame with these columns and dtypes.
- `k` ≥ 1, `max_gap` ≥ 0 and `min_flags` ≥ 1 must be ints (bool not allowed); otherwise `ValueError`. Missing columns and duplicate (date, ticker) rows raise `ValueError`.
- This post-processes ranks. An episode's `end` uses later days, so episodes are for reporting, not for scoring day D.

## Acceptance
`tests/test_detectors_episodes.py`, with 20 business days and ticker AAAA:
- `test_merge_within_gap`: flags on trading days 1, 2, 4 and 9 with `max_gap=2` give two episodes: days 1-4 (3 flags) and day 9 (1 flag).
- `test_gap_zero`: the same flags with `max_gap=0` give three episodes: 1-2, 4 and 9.
- `test_best_rank_and_ids`: `best_rank` is the minimum rank in each episode, and `episode_id` uses the start date.
- `test_min_flags`: `min_flags=2` keeps only the 1-4 episode.
- `test_two_tickers`: another ticker's flags never join AAAA's episodes.
- `test_empty`: no flags give an empty frame with the right columns.
- `test_bad_args`: `k=0`, `max_gap=-1` and a duplicate row each raise.
- `test_input_not_modified`.
