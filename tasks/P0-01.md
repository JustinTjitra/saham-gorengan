# P0-01: Regime schema v2: boards and fixed-rupiah limits

- **Phase:** P0
- **Model:** sonnet
- **Deps:** none

## Goal
Extend the price-limit table so it can hold (a) different boards and (b) limits fixed in rupiah, which IDX uses for the lowest price bands since 2024. No new rows yet; P0-02 and P0-03 add them.

## Interface
New CSV header, exactly:
```
regime_id,board,effective_from,effective_to,price_gt,price_lte,ara_pct,arb_pct,ara_fixed_idr,arb_fixed_idr,decree,source_url,notes
```
Every existing row gets `board=regular`, with `ara_fixed_idr` and `arb_fixed_idr` blank. All other values stay unchanged.

```python
BOARDS = frozenset({"regular", "acceleration", "watchlist"})  # regular = main, development, new economy

@dataclass(frozen=True)
class RegimeTier:
    regime_id: str
    board: str
    effective_from: date
    effective_to: date | None
    price_gt: int
    price_lte: int | None
    ara_pct: int | None
    arb_pct: int | None
    ara_fixed_idr: int | None
    arb_fixed_idr: int | None
    decree: str
    source_url: str
    notes: str

@dataclass(frozen=True)
class PriceLimits:
    regime_id: str
    ara_pct: int | None
    arb_pct: int | None
    ara_fixed_idr: int | None
    arb_fixed_idr: int | None
    def upper(self, reference_price: float) -> float: ...  # ref*(1+ara_pct/100) or ref+ara_fixed_idr
    def lower(self, reference_price: float) -> float: ...  # ref*(1-arb_pct/100) or ref-arb_fixed_idr

def price_limits(day: date, reference_price: float, board: str = "regular") -> PriceLimits: ...
```

## Behaviour
- Each row must have exactly one of `ara_pct` and `ara_fixed_idr`, and exactly one of `arb_pct` and `arb_fixed_idr`. The loader raises `ValueError` naming the regime_id otherwise.
- An unknown `board` value, in the CSV or as an argument, raises `ValueError`.
- `price_limits` only considers tiers of the requested board. A date before that board's first regime raises `ValueError` with "before" in the message.
- Keep the field order of `PriceLimits` keyword-compatible: existing callers use `.ara_pct`, `.arb_pct` and `.regime_id` by name.
