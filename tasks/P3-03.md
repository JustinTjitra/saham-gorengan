# P3-03: Surveillance events schema, loader and suspension-reason classifier

- **Phase:** P3
- **Model:** sonnet
- **Deps:** none
- **Size:** ~150 lines

## Goal
Define the format for IDX surveillance events (UMA notices, suspensions, notations, watchlist-board moves, investigations), and classify suspension reasons from announcement text. The data will live in the private data store, not this repo, so the loader takes a path and the tests use fixtures. This chunk needs no new dependencies.

## Files
- `src/saham_gorengan/surveillance.py` (new)
- `tests/test_surveillance.py` (new)
- `tests/fixtures/surveillance_events.csv` (new; synthetic rows only, using made-up tickers such as `AAAA`, `BBBB` and `example.com` URLs)

## Interface
CSV header, exactly:
```
date,ticker,event_type,reason_class,source,source_url,notes
```
```python
EVENT_TYPES = frozenset({"uma", "suspension", "suspension_lifted", "notation", "watchlist_entry", "watchlist_exit", "investigation"})
REASON_CLASSES = frozenset({"price_up", "price_down", "cooling_down", "late_filing", "listing_fee", "free_float", "going_concern", "non_price_other", "unknown"})
SOURCES = frozenset({"idx_announcement", "news", "manual"})

@dataclass(frozen=True)
class SurveillanceEvent:
    date: date
    ticker: str
    event_type: str
    reason_class: str | None  # set only for event_type == "suspension"; None otherwise
    source: str
    source_url: str
    notes: str

def load_surveillance_events(path: str | Path) -> list[SurveillanceEvent]: ...  # sorted by (date, ticker, event_type)
def classify_suspension_reason(text: str) -> str: ...  # returns a member of REASON_CLASSES
```

## Behaviour
- Loader: use `csv.DictReader` with UTF-8. Every problem raises `ValueError` naming the 1-based line number:
  - a header that differs from the one above;
  - an unknown enum value;
  - a ticker not matching `^[A-Z]{4}$`;
  - an empty `source_url`;
  - a `reason_class` set on a non-suspension row, or blank on a suspension row.
- Duplicate (date, ticker, event_type) rows raise.
- `classify_suspension_reason`: match case-insensitively, after collapsing whitespace, in this order:
  1. "peningkatan harga kumulatif" → `price_up` (even if "cooling down" also appears);
  2. "penurunan harga kumulatif" → `price_down`;
  3. "cooling down" → `cooling_down`;
  4. "laporan keuangan" or "keterlambatan" → `late_filing`;
  5. "biaya pencatatan" → `listing_fee`;
  6. "free float" or "i-a" as a whole word (regex `\bi-a\b`) → `free_float`;
  7. "going concern" or "kelangsungan usaha" → `going_concern`;
  8. any other non-empty text → `non_price_other`;
  9. empty or whitespace-only text → `unknown`.
- The module docstring says these are weak labels: a UMA notice "does not always violate regulations". Cite the research note.
