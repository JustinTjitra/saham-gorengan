# P2-02: Market-adjusted abnormal returns

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P2-00b
- **Size:** ~120 lines

## Goal
Returns net of the market (PLAN.md 3.2, feature 2), so a stock rising on a day the whole market rises doesn't look abnormal. There is no index data yet, so the market is the equal-weighted panel, excluding the stock itself.

## Files
- `src/saham_gorengan/features/market.py` (new)
- `tests/test_features_market.py` (new)

## Interface
```python
def abnormal_returns(bars: pd.DataFrame, horizons: Sequence[int] = (1, 5, 20),
                     min_names: int = 5) -> pd.DataFrame: ...
    """Columns: date, ticker, ret, mkt_ret, then car_<k> for each k in horizons (all float64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input.
- `ret = close / prev_close - 1`, where `prev_close` is the same ticker's previous bar; NaN on a ticker's first row.
- `mkt_ret` for (D, ticker) is the mean `ret` of all **other** tickers with a non-NaN `ret` on D (leave-one-out). It is NaN if fewer than `min_names` other tickers have one.
- `ar = ret - mkt_ret`. `car_<k>` is the sum of `ar` over the ticker's last `k` rows including D. It is NaN unless all `k` values are non-NaN, so `car_1 == ar`.
- `horizons` must be positive integers; otherwise raise `ValueError`.
- No look-ahead: row D uses only rows dated D or earlier. Same-day returns of other tickers are known at the close of D.

## Acceptance
`tests/test_features_market.py`:
- `test_leave_one_out_hand_example`: three tickers AAAA, BBBB, CCCC on two days. Day 1 closes are all 100. Day 2 closes are 110, 100 and 96 (rets 0.10, 0.00, -0.04). With `min_names=2`, day 2 gives `mkt_ret` -0.02, 0.03, 0.05 and `car_1` 0.12, -0.03, -0.09.
- `test_min_names`: the same frame with the default `min_names=5` gives NaN `mkt_ret` and `car_1`.
- `test_car_needs_full_window`: with `horizons=(1, 5)`, `car_5` is NaN on each ticker's first 5 rows (row 1 has no `ret`) and equals the sum of the last five `car_1` values on row 6.
- `test_pump_shows_up`: on `synthetic_bars(n_tickers=10, seed=0, pumps=[Pump("SYAB", date(2022, 6, 1))])`, SYAB's `car_5` on its 5th pump day is > 0.4.
- `test_bad_horizons_raise`: `horizons=(0,)` and `horizons=(5, -1)` raise.
- `test_no_lookahead`: `assert_no_lookahead(abnormal_returns, synthetic_bars(n_tickers=8))` passes.
- `test_input_not_modified`.

## Out of scope
IHSG or sector indices; excluding corporate-action days (P2-08 masks them); bucket-relative returns (P2-05).
