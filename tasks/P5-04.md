# P5-04: Alert-burden and weak-label overlap metrics

- **Phase:** P5
- **Model:** sonnet
- **Deps:** P5-01
- **Size:** ~90 lines

## Goal
PLAN.md 3.4 requires reporting alert burden (how many flags, on how many distinct stocks) and the share of flags that fall on weakly labelled stock-days, such as ARA runs or surveillance events. Weak-label numbers are reported separately and never used for tuning.

## Files
- `src/saham_gorengan/evaluation/burden.py` (new)
- `tests/test_evaluation_burden.py` (new)

## Interface
```python
def alert_stats(ranks: pd.DataFrame, k: int = 25, weak: pd.DataFrame | None = None) -> dict[str, float]: ...
    """ranks: date, ticker, rank (Int64). weak: date, ticker, weak ("boolean"), e.g. ara_episode from P3-02.
    Returns flags_per_day, distinct_tickers, flags_per_ticker, and when weak is given
    share_flags_weak and share_weak_flagged."""
```

## Behaviour
- A flag is a row with `rank <= k`; NA is not a flag. Days are the unique dates in `ranks`.
- `flags_per_day` = flags / number of days. `distinct_tickers` = the number of tickers flagged at least once. `flags_per_ticker` = flags / `distinct_tickers` (NaN if there are none).
- With `weak`, join on (date, ticker); rows missing from `weak` count as not weak. `weak` NA counts as not weak.
  - `share_flags_weak` = weak flags / flags (NaN if no flags).
  - `share_weak_flagged` = weak rows that are flagged / weak rows present in `ranks` (NaN if none).
- Validate `k` (int ≥ 1, bool rejected), required columns and duplicate (date, ticker) in either frame (`ValueError`). Inputs are not modified. Return plain Python floats.

## Acceptance
`tests/test_evaluation_burden.py`, on 4 days × 5 tickers with hand-set ranks:
- `test_counts`: with ranks set so 6 rows have rank ≤ 2 across 3 distinct tickers, `k=2` gives `flags_per_day` 1.5, `distinct_tickers` 3 and `flags_per_ticker` 2.0.
- `test_weak_overlap`: 4 weak rows, 3 of them flagged, and 6 flags in all give `share_flags_weak` 0.5 and `share_weak_flagged` 0.75.
- `test_no_flags`: `k=1` with no rank 1 anywhere gives `flags_per_day` 0, `distinct_tickers` 0 and NaN shares.
- `test_bad_input`: `k=0`, a missing column and a duplicate row each raise.
- `test_inputs_not_modified`.
