## Interface
```python
BAR_COLUMNS: dict[str, str]  # column -> pandas dtype, in this order:
# date: "datetime64[ns]" (normalised to midnight, no timezone)
# ticker: "string"           (4 uppercase letters)
# open, high, low, close: "float64"
# adj_close: "float64"       (nullable; NaN when the source has none)
# volume: "float64"          (shares; NaN = unknown, 0 = no trades)
# value: "float64"           (IDR; nullable)
# frequency: "Int64"         (number of trades; nullable)
# foreign_buy, foreign_sell: "float64"  (shares; nullable)
# listed_shares, tradeable_shares: "float64" (nullable)
# source: "string"

class BarsValidationError(ValueError): ...

def empty_bars() -> pd.DataFrame: ...                  # zero rows, exact columns and dtypes
def validate_bars(df: pd.DataFrame) -> pd.DataFrame: ...  # returns a coerced copy, sorted by (date, ticker)
```

## Behaviour
- Missing *optional* columns (`adj_close`, `value`, `frequency`, `foreign_buy`, `foreign_sell`, `listed_shares`, `tradeable_shares`) are added as nulls.
- Missing *required* columns (`date`, `ticker`, `open`, `high`, `low`, `close`, `volume`, `source`) raise.
- Extra columns raise.
- `validate_bars` collects **all** problems, then raises one `BarsValidationError` listing each with up to 5 example rows. It checks:
  - duplicate (date, ticker) pairs;
  - tickers not matching `^[A-Z]{4}$`;
  - non-positive open, high, low or close;
  - high below max(open, close, low), or low above min(open, close, high);
  - negative volume, value or frequency;
  - dates with a time component or timezone.
- Never modifies the input DataFrame.

## Acceptance
`tests/test_bars.py`:
- A valid 3-row frame round-trips with the exact dtypes and order.
- Each check above has its own failing test. One more test has two problems at once and asserts that both are in the message.
- `empty_bars()` passes `validate_bars`.
- A missing optional column is filled with nulls; a missing required column raises.

## Out of scope
Reading or writing files; any data source.
