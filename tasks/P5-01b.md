# P5-01b: Placebo windows and random-ranker baseline

- **Phase:** P5
- **Model:** sonnet
- **Deps:** P5-01
- **Size:** ~130 lines

## Goal
PLAN.md 3.4 makes these mandatory. "Any day in the top-k" is easy to hit by chance on long windows: a random top-20 out of about 900 stocks hits a 20-day window about 36% of the time. Every recall figure must be reported next to (a) the same metric on placebo windows of matching length in random stocks of the same liquidity bucket and (b) a random ranker.

## Files
- `src/saham_gorengan/evaluation/placebo.py` (new)
- `tests/test_evaluation_placebo.py` (new)

## Interface
```python
def placebo_windows(windows: pd.DataFrame, panel: pd.DataFrame, n_per_window: int = 20,
                    seed: int = 0) -> pd.DataFrame: ...
    """windows: window_id, ticker, start, end. panel: date, ticker, liq_bucket (e.g. from build_features).
    Output: window_id (f"{orig}-P{i:02d}"), orig_window_id, ticker, start, end (one row per placebo)."""

def random_ranks(ranks: pd.DataFrame, seed: int = 0) -> pd.DataFrame: ...
    """Same rows as `ranks` (date, ticker, rank); on each date the ranks of the non-NA rows are randomly permuted."""
```

## Behaviour
- Trading days are the sorted unique dates in `panel`. A real window's **length** L is its number of trading days in [start, end]. Windows with L = 0 get no placebos.
- The real ticker's **bucket** is its `liq_bucket` on the last panel date ≤ `start` where it is non-NA. If none exists, the bucket is "any".
- For each placebo:
  - pick a random ticker, other than the real one, that has the same bucket on its chosen start date ("any" allows every ticker);
  - pick a random start index so the L-day span fits inside the panel's trading days, with `end` the span's last day;
  - reject and redraw if the span overlaps any real window of the same ticker.
  - Use `numpy.random.default_rng(seed)` only. After 1,000 failed draws for one placebo, raise `RuntimeError` naming the window.
- `random_ranks`: for each date, randomly permute the existing non-NA rank values among the non-NA rows. NA ranks stay NA. The same seed gives the same output.
- Neither input is modified. Output has a fresh RangeIndex.

## Acceptance
`tests/test_evaluation_placebo.py`, with a hand-built panel of 40 tickers × 120 business days in 2024, half in bucket 1 and half in bucket 2:
- `test_lengths_match`: every placebo spans the same number of trading days as its real window.
- `test_same_bucket_and_other_ticker`: placebos for a bucket-1 window use bucket-1 tickers, never the real ticker.
- `test_deterministic`: the same seed gives identical output; a different seed gives different output.
- `test_no_overlap_with_real_windows`: a placebo on a ticker with a real window never overlaps it.
- `test_random_ranks_permutes`: each date keeps the same multiset of ranks and the same NA positions.
- `test_random_ranker_hit_rate`: with 200 tickers ranked on each of 250 days (rank 1..200), `random_ranks`, `k=10` and 500 placebo 20-day windows, the mean `found` from `window_metrics(..., lead=0)` is between 0.55 and 0.73 (theory: 1 - 0.95^20 ≈ 0.64).
- `test_inputs_not_modified`.
