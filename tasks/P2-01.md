# P2-01: Limit-normalised returns, limit-hit flags and ARA run length

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P1-01
- **Size:** ~140 lines

## Goal
The first feature: returns scaled by the price limit in force, ARA and ARB hit flags, and the length of the current ARA run. These make returns comparable across limit regimes (PLAN.md 3.2, feature 1).

## Files
- `src/saham_gorengan/features/__init__.py` (new; may be empty apart from a docstring)
- `src/saham_gorengan/features/limits.py` (new)
- `tests/test_features_limits.py` (new)

## Interface
```python
def limit_features(bars: pd.DataFrame, board: str = "regular") -> pd.DataFrame: ...
    """Columns: date, ticker, ret (float64), ret_norm (float64), ara_hit ("boolean"), arb_hit ("boolean"), ara_run (Int64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input. `prev` is the same ticker's previous close, whatever the gap.
- `ret = close / prev - 1`.
- Let `lim = price_limits(day, prev, board)`, `up = lim.upper(prev)` and `dn = lim.lower(prev)`:
  - `ret_norm = ret / (up / prev - 1)` when `ret >= 0`, else `ret / (1 - dn / prev)`. A close exactly at a limit gives +1 or -1.
  - `ara_hit = close >= round_to_tick(up, day, "down")`;
  - `arb_hit = close <= round_to_tick(dn, day, "up")`.
- `ara_run`: consecutive `ara_hit` days ending at D for that ticker, so 1 on the first hit day and 0 when `ara_hit` is False. NA when `ara_hit` is NA, and an NA day resets the count.
- With no previous bar, or when `price_limits` or `round_to_tick` raises `ValueError`, every column except date and ticker is NA for that row.
- No look-ahead: row D uses only rows dated D or earlier.
- Cache `price_limits` and `round_to_tick` calls with a bounded `lru_cache`, as in `quality.py`.

## Acceptance
`tests/test_features_limits.py`:
- `test_pct_regime_2024`: on 2024-01-02 (35/35), prev 100:
  - close 135 → ret 0.35, ret_norm 1.0, ara_hit True;
  - close 120 → ret_norm ≈ 0.2 / 0.35, ara_hit False;
  - close 65 → ret_norm -1.0, arb_hit True.
- `test_asymmetric_2025`: on 2025-05-02 (ARB 15%), prev 100, close 85 → ret_norm -1.0, arb_hit True. Close 90 → ret_norm ≈ -0.10 / 0.15.
- `test_ara_run`: one ticker on consecutive 2024 days with closes 100, 135, 182, 244, 240 → ara_hit NA, T, T, T, F and ara_run NA, 1, 2, 3, 0. Worked through: the upper of 135 is 182.25, which rounds down to 182 at tick 1. The upper of 182 is 245.7, which rounds down to 244 at tick 2.
- `test_fixed_rp1_band`: on 2026-10-20, prev 8, close 9 → ara_hit True and ret_norm 1.0.
- `test_first_row_na`: a ticker's first row has every feature NA.
- `test_no_lookahead`: for each date D, `limit_features(bars[bars.date <= D])` equals the full result restricted to dates <= D.
- `test_input_not_modified`.
