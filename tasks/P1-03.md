# P1-03: Source protocol and Yahoo adapter (mocked)

- **Phase:** P1
- **Model:** sonnet
- **Deps:** P1-01

## Goal
A common interface for daily data sources, and the first implementation, for Yahoo Finance via `yfinance`. It is tested entirely offline. Live use waits until the environment allows Yahoo's hosts.

## Files
- `src/saham_gorengan/sources/__init__.py` (new)
- `src/saham_gorengan/sources/base.py` (new)
- `src/saham_gorengan/sources/yahoo.py` (new)
- `tests/test_source_yahoo.py` (new)
- `pyproject.toml`: add the optional extra `yahoo = ["yfinance>=0.2.50", "curl_cffi"]`. Do **not** add it to the core or `test` dependencies.

## Interface
```python
class DailySource(Protocol):
    name: str
    def fetch(self, tickers: Sequence[str], start: date, end: date) -> pd.DataFrame: ...  # bars schema

class SourceError(RuntimeError): ...

class YahooSource:
    name = "yahoo"
    def __init__(self, max_retries: int = 5, base_delay: float = 2.0,
                 sleep: Callable[[float], None] = time.sleep) -> None: ...
    def fetch(self, tickers, start, end) -> pd.DataFrame: ...
```

## Behaviour
- Import `yfinance` lazily inside `fetch`. If it isn't installed, raise `SourceError("pip install saham-gorengan[yahoo]")`.
- Map each ticker to `<TICKER>.JK`. Call `yfinance.download(symbols, start=start, end=end + 1 day, interval="1d", auto_adjust=False, actions=False, group_by="ticker", progress=False, threads=False)`.
- `auto_adjust=False` is essential: limit-hit features need raw prices. Store Yahoo's `Adj Close` in `adj_close`.
- Output columns:
  - `value`, `frequency`, `foreign_*` and the share columns are null;
  - `source` is `"yahoo"`;
  - drop rows where all of OHLC are NaN;
  - tickers with no data are silently absent, but logged with `logging.getLogger(__name__).info`.
- **Retries:** catch exceptions whose class name contains "RateLimit", plus `ConnectionError`. Retry with delay `base_delay * 2**attempt` via the injected `sleep`. After `max_retries`, raise `SourceError`.
- The result passes `validate_bars`.

## Acceptance
`tests/test_source_yahoo.py`. Inject a fake `yfinance` module with `monkeypatch.setitem(sys.modules, "yfinance", fake)`; the real package must not be needed.
- A two-ticker MultiIndex-column frame (group_by="ticker" layout) converts to valid bars, with `.JK` stripped and `adj_close` filled.
- The call is made with `auto_adjust=False`, and `end` is passed as end + 1 day.
- An all-NaN ticker is dropped.
- Rate limits: a fake raising a `YFRateLimitError`-named exception twice, then succeeding, results in 2 sleeps of 2.0 and 4.0.
- Exhausted retries raise `SourceError`.
- A missing module raises `SourceError` with the install hint (use `monkeypatch.setitem(sys.modules, "yfinance", None)`).

## Out of scope
Writing to the store; a backfill command; any real network call.
