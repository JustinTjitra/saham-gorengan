# P2-00b: assert_no_lookahead test helper

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P2-00a
- **Size:** ~100 lines

## Goal
One reusable check that any feature function only uses data up to day D. Every feature chunk in Phase 2 must call it.

## Files
- `src/saham_gorengan/testing.py` (add to it)
- `tests/test_testing_lookahead.py` (new)

## Interface
```python
def assert_no_lookahead(feature_fn: Callable[[pd.DataFrame], pd.DataFrame], bars: pd.DataFrame,
                        check_dates: Sequence[date] | None = None, n_checks: int = 5,
                        atol: float = 1e-9) -> None: ...
```

## Behaviour
- `feature_fn` takes a bars frame and returns a DataFrame with `date` and `ticker` columns plus feature columns, one row per input (date, ticker).
- Compute `full = feature_fn(bars)`.
- Choose check dates: use `check_dates` if given; otherwise pick `n_checks` dates evenly spaced over the last 80% of the panel's unique dates, which leaves warm-up room.
- For each D: `trunc = feature_fn(bars[bars.date <= D])`. Compare the rows for date D in `full` and in `trunc` on every feature column, with NaN equal to NaN and absolute tolerance `atol`.
- On the first mismatch, raise `AssertionError` naming D, the ticker, the column and both values.
- Never mutate `bars`.

## Acceptance
`tests/test_testing_lookahead.py`, using `synthetic_bars(n_tickers=5)`:
- A 20-day trailing mean of close per ticker passes.
- A leaky feature (next day's close via `groupby().shift(-1)`) raises `AssertionError`, and the message contains "close" or the feature name.
- A feature using the full-sample mean per ticker raises.
- The input frame is unchanged after the call.

## Out of scope
Any real feature.
