# P2-04: Run-up and drawdown features

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P2-00b
- **Size:** ~90 lines

## Goal
Run-up and reversal features (PLAN.md 3.2, feature 4): how far a stock has climbed over 5 and 20 days, and how far it sits below its recent peak. A pump shows a large run-up, and the dump shows a deep drawdown right after it.

## Files
- `src/saham_gorengan/features/runup.py` (new)
- `tests/test_features_runup.py` (new)

## Interface
```python
def runup_features(bars: pd.DataFrame, window: int = 20) -> pd.DataFrame: ...
    """Columns: date, ticker, cumret_5, cumret_20, runup_20, drawdown_20 (all float64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input. Windows count the ticker's rows, not calendar days.
- `cumret_k = close / close k rows earlier - 1`, for k = 5 and k = `window`. NaN until the ticker has k earlier rows.
- `runup_20 = close / min(close over the last window rows including D) - 1`.
- `drawdown_20 = close / max(close over the last window rows including D) - 1`, so it is ≤ 0.
- `runup_20` and `drawdown_20` are NaN until the ticker has `window` rows.
- `window` < 2 raises `ValueError`. The column names keep the `_20` suffix whatever `window` is (simplest; document it).
- No look-ahead.

## Acceptance
`tests/test_features_runup.py`:
- `test_linear_climb`: one ticker with 21 rows closing 100, 101, ..., 120. On row 21: `cumret_20` = 0.2, `cumret_5` ≈ 0.0434783, `drawdown_20` = 0.0, `runup_20` ≈ 0.1881188 (the window is rows 2-21, minimum 101).
- `test_drop_after_peak`: the same ticker with a 22nd row closing 108. On row 22: `drawdown_20` = -0.1, `runup_20` ≈ 0.0588235 (window rows 3-22, minimum 102).
- `test_warmup_nan`: rows 1-5 have NaN `cumret_5`; rows 1-19 have NaN `runup_20` and `drawdown_20`.
- `test_pump_then_dump`: on `synthetic_bars(n_tickers=5, seed=0, pumps=[Pump("SYAB", date(2022, 6, 1))])`, SYAB's `runup_20` on its last pump day is > 1.0, and its `drawdown_20` on its last dump day is < -0.3.
- `test_bad_window`: `window=1` raises.
- `test_no_lookahead`: `assert_no_lookahead(runup_features, synthetic_bars(n_tickers=5))` passes.
- `test_input_not_modified`.
