# P0-06: Label update: convicted and exchange_review classes

- **Phase:** P0
- **Model:** sonnet
- **Deps:** P0-02
- **Size:** ~120 lines changed

## Goal
Record two developments from November 2026: the SWAT criminal verdict, and IDX's first public trading investigations (NSSS, FUJI, CASA). Each gets its own label class so evaluation can include or exclude it explicitly.

## Files
- `data/cases.csv`
- `data/windows.csv`
- `src/saham_gorengan/_load.py`
- `src/saham_gorengan/_query.py`
- `tests/test_data_integrity.py`
- `tests/test_api.py`
- `README.md` (the label-class and confidence sections, and the counts in "Read this before using it as training data")

## Behaviour
- `LABEL_CLASSES` becomes {`sanctioned`, `convicted`, `alleged`, `exchange_review`}.
- `STATUSES` adds `convicted` and `exchange_investigation`.
- Allowed class-to-status pairs:

| Class | Allowed statuses |
|---|---|
| sanctioned | sanctioned |
| convicted | convicted |
| alleged | referred_to_prosecutor, under_investigation |
| exchange_review | exchange_investigation |

- **SWAT-2018:** class `convicted`, status `convicted`, for both the case and its window. Append to its notes: "Supreme Court rejected cassation on 2026-11-06 (No. 13409 K/PID.SUS/2026; 10 months and Rp500m fine for SA). Reported by Kontan only; verify against the ruling."
- **New cases**, each with class `exchange_review`, status `exchange_investigation` and confidence C:
  - NSSS-2025
  - FUJI-2026
  - CASA-2026

  Use the announcement date, scheme text and source URLs from `research_notes/IDX manipulation detector sources/surveillance_weak_labels.md` section 2. Leave fine fields blank.
- **New windows**, all with day precision, class `exchange_review` and confidence C:
  - NSSS: 2025-12-01 to 2026-10-30
  - FUJI: 2026-03-02 to 2026-10-30
  - CASA: 2026-10-26 to 2026-11-02 (notes: "about 98% of trading by 6 investors")
- `labels_on()` default `classes` becomes `("sanctioned", "convicted")`.
- In `README.md`, change OJK's case count for 2022 to early 2026 from "29" to "about 29 to 32". A figure of 32 cases is also reported for the same period.
