# P2-00a: Synthetic panel generator with pump injection

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P1-01
- **Size:** ~150 lines

## Goal
Deterministic synthetic daily panels with known, injected pump-and-dump episodes. Every feature and detector can then be tested offline, and recovery of the injected episodes is the first sanity check.

## Files
- `src/saham_gorengan/testing.py` (new)
- `tests/test_testing_synthetic.py` (new)

## Interface
```python
@dataclass(frozen=True)
class Pump:
    ticker: str
    start: date          # first pump day (inclusive)
    pump_days: int = 10
    daily_return: float = 0.15   # mean return per pump day
    volume_mult: float = 8.0     # volume multiplier during the pump and dump
    dump_days: int = 5
    dump_return: float = -0.12

def synthetic_bars(n_tickers: int = 20, start: date = date(2022, 1, 3), end: date = date(2022, 12, 30),
                   seed: int = 0, pumps: Sequence[Pump] = ()) -> pd.DataFrame: ...
```

## Behaviour
- Trading days are Monday to Friday (`pd.bdate_range`), with no holidays.
- Tickers are `SYAA`, `SYAB`, `SYAC`, ... (prefix `SY` plus two letters, in order). These four-letter codes pass `validate_bars`, and the `SY` prefix keeps them distinct from real IDX tickers.
- **Prices:** each ticker starts at a random price between 100 and 2000. Daily log-returns are drawn from N(0, 0.02). Open = previous close × (1 + small noise); high and low bracket open and close. Round to 0 decimal places and keep everything ≥ 1.
- **Volume:** lognormal around a per-ticker base, with `source="synthetic"`, `value = close * volume`, and `frequency = round(volume / 500)`.
- **Pumps:**
  - For `pump_days` trading days from `start`, add `daily_return` to the log-return, with noise sd 0.02.
  - For the next `dump_days`, use `dump_return`.
  - Multiply volume by `volume_mult` on all pump and dump days.
  - A pump whose ticker isn't generated, or which runs past `end`, raises `ValueError`.
- The same seed produces an identical frame.
- Output passes `validate_bars`.

## Acceptance
- `test_valid_and_deterministic`
- `test_shape`: n_tickers × number of business days in the range.
- `test_pump_signature`:
  - inside the pump window, the mean log-return is > 0.08;
  - inside the pump window, mean volume is > 4× that ticker's mean volume outside it;
  - over the dump days, the mean return is < -0.05.
- `test_bad_pump_raises`

## Out of scope
Look-ahead helper (P2-00b); realistic price limits (later features clip using regimes).
