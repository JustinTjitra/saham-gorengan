# P2-03: Robust volume, turnover and value z-scores

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P2-00b
- **Size:** ~140 lines

## Goal
Abnormal-activity features (PLAN.md 3.2, feature 3): how unusual today's volume, turnover and traded value are against the ticker's own recent history, measured robustly so that one earlier spike doesn't hide the next.

## Interface
```python
def volume_features(bars: pd.DataFrame, window: int = 60, min_periods: int = 20) -> pd.DataFrame: ...
    """Columns: date, ticker, vol_z, turnover, turnover_z, value_z, zero_vol_share (all float64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input.
- `turnover = volume / tradeable_shares` where `tradeable_shares` is present, else `volume / listed_shares`, else NaN.
- **Robust z of a series x for row D** (computed per ticker on `log1p(x)`):
  - the baseline is the previous `window` rows of that ticker, **excluding D itself**, ignoring NaN;
  - if the baseline has fewer than `min_periods` values, the result is NaN;
  - `z = (log1p(x_D) - median) / (1.4826 * MAD)`, where `MAD = median(|baseline - median|)`;
  - if MAD is 0, the result is NaN; if `x_D` is NaN, the result is NaN.
- `vol_z`, `turnover_z` and `value_z` apply that to `volume`, `turnover` and `value`. Turnover is scaled by 1e6 before `log1p` so small fractions don't vanish.
- `zero_vol_share`: the share of rows with `volume == 0` among the last `window` rows of that ticker **including D**, ignoring NaN volume. NaN until `min_periods` non-NaN volumes are available.
- Windows count rows of the ticker, not calendar days (missing days are absent rows).
- No look-ahead: row D uses only rows dated D or earlier.

## Acceptance
`tests/test_features_volume.py`:
- `test_hand_example`: one ticker whose first 20 rows have `log1p(volume)` alternating 10, 11, 10, 11, ... (volume = `expm1` of those) and whose 21st row has `log1p(volume) = 13`. The 21st row's `vol_z ≈ 3.3725` (median 10.5, MAD 0.5, so 2.5 / 0.7413). Rows 1-20 have NaN `vol_z`.
- `test_constant_volume_is_nan`: a constant volume gives MAD 0, so `vol_z` is NaN.
- `test_pump_lights_up`: on `synthetic_bars(n_tickers=5, seed=0, pumps=[Pump("SYAB", date(2022, 6, 1))])`, the mean `vol_z` over SYAB's pump days is > 3, and the median `vol_z` over all other tickers' rows after the warm-up is between -1 and 1.
- `test_turnover_prefers_tradeable`: with both share columns set, `turnover = volume / tradeable_shares`; with only `listed_shares`, it uses that; with neither, it is NaN.
- `test_zero_vol_share`: a ticker with 25 rows where rows 21-25 have volume 0 and the rest 1000 gives `zero_vol_share` on row 25 = 5 / 25 with `window=60, min_periods=20`.
- `test_no_lookahead`: `assert_no_lookahead(volume_features, synthetic_bars(n_tickers=5))` passes.
- `test_input_not_modified`.
