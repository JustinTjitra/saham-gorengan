## Goal
A command that scores one trading day from the local Parquet store and prints the top k. It is the core of the daily job (D7). Writing the watchlist file, with explanations and wording rules, is P6-02.

## Files
- `src/saham_gorengan/cli.py` (new)

## Interface
```python
def score_day(day: date, root: str | Path | None = None, k: int = 25, history_days: int = 400) -> pd.DataFrame: ...
    """Top-k composite ranks for `day`: columns date, ticker, rank (Int64), score (float64), sorted by rank."""

def main(argv: Sequence[str] | None = None) -> int: ...
    """argparse entry point; subcommand `score --date YYYY-MM-DD [--data-dir DIR] [--k N]`. Returns the exit code."""
```

## Behaviour
- `score_day` reads bars with `read_bars(day - timedelta(days=history_days), day, root=root)`. It never reads past `day` (no look-ahead). It runs `build_features` and then `composite_scores`, and keeps the rows for `day` with rank ≤ k. `score` is the composite's score column.
- When the store has no bars dated `day`, `score_day` raises `ValueError("no bars for <day>")`. It raises `ValueError` for k < 1 or `history_days` < 30.
- `main`:
  - prints the frame as CSV to stdout (columns date, ticker, rank, score; date as YYYY-MM-DD) and returns 0;
  - on `ValueError`, prints `error: <message>` to stderr and returns 2;
  - with no subcommand, prints usage and returns 2.
- `--data-dir` is passed as `root` (defaults to `SAHAM_DATA_DIR` through `store_root`). No network access, no writes.
- Output describes ranks only. Print no words like "manipulated" or "gorengan".

## Acceptance
`tests/test_cli.py`, using `tmp_path` as the store and `write_bars(synthetic_bars(n_tickers=30, start=2024-01-02, end=2024-12-31, seed=0, pumps=[one strong Pump]), root=tmp_path)`:
- `test_score_day_topk`: on a day inside the pump, the result has ≤ k rows, ranks 1..n, and the pump ticker at rank ≤ 3.
- `test_no_lookahead`: `score_day` on day D equals `score_day` on D after bars dated after D have been deleted from a second store.
- `test_missing_day`: a weekend date raises `ValueError` mentioning "no bars".
- `test_main_csv`: `main(["score", "--date", ..., "--data-dir", str(tmp_path), "--k", "5"])` returns 0, and the captured stdout parses as CSV with 5 rows and the right header.
- `test_main_error`: a missing day returns 2 and writes `error:` to stderr.
- `test_bad_args`: k=0 and history_days=10 raise.
