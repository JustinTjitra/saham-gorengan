# P3-02: ARA-run weak label

- **Phase:** P3
- **Model:** sonnet
- **Deps:** P2-01
- **Size:** ~90 lines

## Goal
A weak label for evaluation: runs of consecutive auto-rejection-above (ARA) closes. PLAN.md 3.4 reports weak-label results separately from the OJK labels and never tunes on them. A long ARA run is a price extreme, not proof of manipulation.

## Files
- `src/saham_gorengan/weak_labels.py` (new)
- `tests/test_weak_labels.py` (new)

## Interface
```python
def ara_run_label(bars: pd.DataFrame, min_run: int = 3, board: str = "regular") -> pd.DataFrame: ...
    """Columns: date, ticker, ara_episode ("boolean", never NA), episode_id (string), run_len (Int64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Compute `limit_features(bars, board)` (P2-01). NA `ara_hit` counts as False.
- An **episode** is a maximal run of consecutive rows of one ticker with `ara_hit` True, of length ≥ `min_run`. Every row in it gets `ara_episode` True, `episode_id = f"{ticker}-{start:%Y%m%d}"` (the run's first date) and `run_len` = the run's total length. Other rows get False, NA and NA.
- This is a **label** and uses the whole run, including days after D. The module docstring must say it must never be a detector input, and that an ARA run is a statistical extreme, not a finding of manipulation.
- `min_run` must be an int ≥ 1 (bool not allowed), else `ValueError`.

## Acceptance
`tests/test_weak_labels.py`, with 2024 dates (35% tier under Rp200):
- `test_three_day_run`: ticker AAAA closing 100, 135, 182, 244, 240 (P2-01 gives ara_hit NA, T, T, T, F). With `min_run=3`, rows 2-4 are True with `run_len` 3 and `episode_id` "AAAA-" plus row 2's date. Rows 1 and 5 are False.
- `test_min_run_filters`: the same data with `min_run=4` gives no episode.
- `test_two_tickers_independent`: a second ticker with one ARA day is not labelled, and AAAA's labels are unchanged.
- `test_bad_min_run`: 0 and `True` raise.
- `test_input_not_modified`.

## Out of scope
UMA and suspension weak labels (P3-03 and P3-04 supply their data); using weak labels in tuning.
