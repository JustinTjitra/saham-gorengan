# P2-07: Trade-size and foreign-flow features (null-safe)

- **Phase:** P2
- **Model:** sonnet
- **Deps:** P2-03
- **Size:** ~100 lines

## Goal
Trade-size and foreign-flow features (PLAN.md 3.2, features 7-8). They need trade counts and foreign buy/sell, which Yahoo doesn't supply, so they must return NaN cleanly when those columns are empty and work as soon as a richer source fills them.

## Files
- `src/saham_gorengan/features/tradesize.py` (new)
- `tests/test_features_tradesize.py` (new)

## Interface
```python
def tradesize_features(bars: pd.DataFrame, window: int = 60, min_periods: int = 20) -> pd.DataFrame: ...
    """Columns: date, ticker, value_per_trade, vpt_z, freq_z, net_foreign (all float64).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input.
- `value_est` is computed as in P2-05: `value` where present, else `close * volume`.
- `value_per_trade = value_est / frequency`. NaN when `frequency` is NA or 0.
- `vpt_z` and `freq_z` are robust z-scores of `value_per_trade` and `frequency`. Use the same definition, window and baseline rules as P2-03 by reusing the private `_robust_z` helper in `features/volume.py`. Do not copy it.
- `net_foreign = (foreign_buy - foreign_sell) / volume`. NaN when either foreign column is NaN or `volume` is NaN or 0.
- A frame whose `frequency` and foreign columns are entirely null returns all-NaN feature columns, with no error and no warning.
- No look-ahead.

## Acceptance
`tests/test_features_tradesize.py`:
- `test_value_per_trade`: `value` 1e6 with `frequency` 100 gives 1e4; `frequency` 0 gives NaN; NA `frequency` gives NaN.
- `test_freq_z_hand_example`: one ticker whose first 20 rows have `log1p(frequency)` alternating 10, 11 (frequency = `round(expm1(...))`; accept a tolerance of 1e-3 for the rounding) and whose 21st row has `log1p(frequency) = 13`. Row 21 has `freq_z ≈ 3.3725`.
- `test_net_foreign`: buy 300, sell 100 and volume 1000 give 0.2; volume 0 gives NaN.
- `test_yahoo_like_all_null`: bars with no `frequency` or foreign columns (they become null in `validate_bars`) give NaN in all four feature columns.
- `test_no_lookahead`: `assert_no_lookahead(tradesize_features, synthetic_bars(n_tickers=5))` passes. The synthetic panel has `frequency`.
- `test_input_not_modified`.

## Out of scope
Broker-level data; non-regular-market trades.
