# P1-02: Month-partitioned Parquet store

- **Phase:** P1
- **Model:** sonnet
- **Deps:** P1-01
- **Size:** ~150 lines

## Goal
Read and write the daily panel as Parquet files partitioned by month, in a directory **outside this repo** (the private data store).

## Files
- `src/saham_gorengan/store.py` (new)
- `tests/test_store.py` (new)
- `.gitignore` (add `/store/` as a safety net)

## Interface
```python
def store_root(root: str | Path | None = None) -> Path: ...
# Uses the argument, else env var SAHAM_DATA_DIR. Raises RuntimeError if neither is set,
# or if the path resolves inside this git repo, unless it is <repo>/store/ (gitignored).

def write_bars(df: pd.DataFrame, root: str | Path | None = None) -> list[Path]: ...
# validate_bars first; writes <root>/bars/year=YYYY/month=MM/bars.parquet; returns the files written.

def read_bars(start: date, end: date, tickers: Iterable[str] | None = None,
              root: str | Path | None = None) -> pd.DataFrame: ...
# inclusive dates; returns validated bars; empty_bars() if nothing matches.
```

## Behaviour
- **Merge on write:** for each month touched, read the existing file if there is one, concatenate the new rows, and drop duplicate (date, ticker) pairs, **keeping the newly written row**. Write to a temp file in the same folder, then `os.replace` it, so a crash never leaves a half-written file.
- Reading only opens the month files the date range overlaps.
- Use pyarrow through pandas (`to_parquet` / `read_parquet` with `engine="pyarrow"`), with zstd compression.

## Acceptance
`tests/test_store.py`, using `tmp_path`:
- A write-then-read round trip is equal (`pd.testing.assert_frame_equal`).
- Rows spanning 2 months create 2 files.
- Rewriting an overlapping day replaces the old row and keeps the others.
- `read_bars` filters by date range and by tickers.
- A missing root raises when the env var is unset (use `monkeypatch.delenv`).
- A root inside the repo (other than `store/`) raises.

## Out of scope
Feature tables; remote storage or sync; any data source.
