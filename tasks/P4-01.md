# P4-01: Baseline rankers

- **Phase:** P4
- **Model:** sonnet
- **Deps:** P2-01, P2-03
- **Size:** ~100 lines

## Goal
The baseline detectors from PLAN.md 3.3: rank stocks each day by limit-normalised return, by abnormal volume, and by a simple rule that approximates a UMA notice. Every later detector must beat these to stay.

## Files
- `src/saham_gorengan/detectors/__init__.py` (new; docstring only)
- `src/saham_gorengan/detectors/baselines.py` (new)
- `tests/test_detectors_baselines.py` (new)

## Interface
```python
def baseline_scores(features: pd.DataFrame, rule_ret_norm: float = 0.8, rule_vol_z: float = 3.0) -> pd.DataFrame: ...
    """Input: columns date, ticker, ret_norm, vol_z (other columns ignored).
    Output columns: date, ticker, s_ret, s_vol, s_rule (float64), rank_ret, rank_vol, rank_rule (Int64)."""
```

## Behaviour
- The input is a feature frame, such as the outputs of `limit_features` and `volume_features` merged on (date, ticker). Missing required columns raise `ValueError`; duplicate (date, ticker) rows raise `ValueError`.
- `s_ret = ret_norm`; `s_vol = vol_z`.
- `s_rule = 1.0` where `ret_norm >= rule_ret_norm` and `vol_z >= rule_vol_z`, `0.0` where both are present and the rule fails, and NaN where either is NaN.
- Ranks are per date, 1 = most suspicious, with no gaps (`method="first"`, ties broken by ticker in ascending order):
  - `rank_ret` by `s_ret` descending, NA where `s_ret` is NaN;
  - `rank_vol` by `s_vol` descending, NA where NaN;
  - `rank_rule` by `s_rule` descending, then `s_ret` descending, NA where `s_rule` is NaN.
- Output is sorted by (date, ticker) with a fresh RangeIndex. The input is not modified.
- No look-ahead: scores for D use only the row for D.

## Acceptance
`tests/test_detectors_baselines.py`, on one date with four tickers:

| ticker | ret_norm | vol_z |
|---|---|---|
| AAAA | 0.90 | 1.0 |
| BBBB | 0.85 | 4.0 |
| CCCC | 0.20 | 5.0 |
| DDDD | -0.50 | NaN |

- `test_rank_ret`: AAAA 1, BBBB 2, CCCC 3, DDDD 4.
- `test_rank_vol`: CCCC 1, BBBB 2, AAAA 3, DDDD NA.
- `test_rule`: `s_rule` is AAAA 0, BBBB 1, CCCC 0, DDDD NaN; `rank_rule` is BBBB 1, AAAA 2, CCCC 3, DDDD NA.
- `test_ranks_per_date`: adding a second date with its own rows doesn't change the first date's ranks.
- `test_bad_input`: a missing `vol_z` column raises, and a duplicate (date, ticker) row raises.
- `test_input_not_modified`.
