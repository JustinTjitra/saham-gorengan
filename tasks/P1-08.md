# P1-08: Corporate-action suspect flags

- **Phase:** P1
- **Model:** sonnet
- **Deps:** P1-07
- **Size:** ~120 lines

## Goal
Flag days that are probably corporate actions (splits, reverse splits, rights or bonus issues) rather than trading. PLAN.md 3.1 says those days are excluded from features, never silently adjusted.

## Files
- `src/saham_gorengan/corporate.py` (new)
- `tests/test_corporate.py` (new)

## Interface
```python
def corporate_action_suspects(bars: pd.DataFrame, board: str = "regular",
                              adj_jump: float = 0.05, ratio_tol: float = 0.03) -> pd.DataFrame: ...
    """Columns: date, ticker, suspect ("boolean"), price_ratio (float64, prev_close / close), kind (string).
    Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input. The previous close is the same ticker's previous bar, as in P1-07.
- `suspect` is True if **either** rule fires:
  1. `quality_flags(bars, board)["beyond_limit"]` is True;
  2. the adjustment factor jumps: with `f = adj_close / close`, `abs(f / f_prev - 1) > adj_jump`, where both days have `adj_close`.
- `suspect` is NA when neither rule can be evaluated (no previous bar, or `beyond_limit` is NA and either `adj_close` is missing). It is False when the rules can be evaluated and neither fires.
- `price_ratio = prev_close / close`, NaN without a previous bar.
- `kind` is set only on suspect rows and is NA elsewhere:
  - `"split"` if `price_ratio` is within `ratio_tol` (relative) of a whole number k >= 2;
  - `"reverse_split"` if `1 / price_ratio` is within `ratio_tol` of a whole number k >= 2;
  - otherwise `"unknown"`.
- Rule 2 uses Yahoo's adjusted close, which Yahoo computes after the fact. That is acceptable for data cleaning, but this flag must never be used as a model feature. Say so in the module docstring.

## Acceptance
`tests/test_corporate.py`, with dates in 2024 (35% limits on the regular board):
- `test_split_detected`: prev close 1000, close 200 → suspect True, kind "split", price_ratio 5.0.
- `test_reverse_split_detected`: prev close 100, close 1000 → suspect True, kind "reverse_split".
- `test_normal_day_not_suspect`: prev close 100, close 110, adj_close equal to close on both days → False, kind NA.
- `test_adj_factor_jump`: close 100 → 100, with adj_close 100 → 90 (f falls 10%) → suspect True, kind "unknown".
- `test_small_dividend_not_flagged`: f falls 2% with the default `adj_jump` → False.
- `test_first_bar_na`: a ticker's first row has suspect NA when adj_close is missing.
- `test_input_not_modified`.

## Out of scope
Adjusting prices; joining with official corporate-action announcements; using the flag in features.
