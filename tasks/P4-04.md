# P4-04: PU ranker, leave-one-case-out

- **Phase:** P4
- **Model:** sonnet
- **Deps:** P5-02, P4-02
- **Size:** ~130 lines

## Goal
Detector 4 of PLAN.md 3.3. It learns what labelled pump windows look like from the other cases, and ranks the held-out case's days with that model. Positives are ticker-days inside sanctioned or convicted windows; every other row is unlabelled (positive-unlabelled learning). This chunk builds and tests the machinery on synthetic pumps. Whether it beats the composite is decided on real cases.

## Files
- `src/saham_gorengan/detectors/pu.py` (new)
- `tests/test_detectors_pu.py` (new)

## Interface
```python
def pu_scores(features: pd.DataFrame, windows: pd.DataFrame, split: Split,
              components: Sequence[str] = DEFAULT_COMPONENTS, C: float = 1.0) -> pd.DataFrame: ...
    """Output: date, ticker, score (float64), rank (Int64) for rows on split.test_days only."""

def pu_loco(features: pd.DataFrame, windows: pd.DataFrame, lead: int = 20, embargo: int = 60,
            components: Sequence[str] = DEFAULT_COMPONENTS, C: float = 1.0) -> dict[str, pd.DataFrame]: ...
    """window_id -> pu_scores output for that window's split (windows with no split are absent)."""
```
`Split` and `loco_splits` come from `evaluation.splits`; `DEFAULT_COMPONENTS` from `detectors.composite`.

## Behaviour
- **Training rows** are the rows on `split.train_days` with every component present. The label is 1 if the row's ticker and date fall inside any window **other than** `split.held_out` (inclusive), else 0.
- Fit `sklearn.linear_model.LogisticRegression(C=C, class_weight="balanced", max_iter=1000)` on the components, standardised with the training rows' mean and std. A std of 0 becomes 1.
- When there are no positive or no negative training rows, raise `ValueError` naming the held-out window.
- **Scoring rows** are the rows on `split.test_days`. `score` = `predict_proba[:, 1]`, NaN where a component is missing. Rank per date with `baselines._rank`.
- The held-out window's own rows are never used in training. The train/test day separation and the embargo from `loco_splits` guarantee this; add an assertion in the code.
- Deterministic (LogisticRegression with the default lbfgs solver needs no seed). Inputs are not modified. No new dependency (scikit-learn is already allowed).

## Acceptance
`tests/test_detectors_pu.py`, on `synthetic_bars(n_tickers=40, start=2024-01-02, end=2024-12-31, seed=0)` with 6 strong default `Pump`s on 6 different tickers, starting at trading days 30, 70, 110, 150, 190 and 230. Windows run from the pump start for 15 trading days. Features come from `build_features`.
- `test_loco_finds_held_out`: `pu_loco(..., lead=0, embargo=20)`. With k=5, `window_metrics` on each held-out window's ranks finds at least 5 of the 6 windows.
- `test_never_trains_on_held_out`: monkeypatch `LogisticRegression.fit` to record its X and y. For each split, no training row has a (date, ticker) inside the held-out window, and the training dates are disjoint from `split.test_days`.
- `test_labels`: on one split, the number of positive training rows equals the count of (ticker, day) pairs inside the other 5 windows that fall on train days with complete components (compute it independently in the test).
- `test_no_positives_raises`: with a single window, its split has no positives, so it raises `ValueError`.
- `test_deterministic` and `test_inputs_not_modified`.
