# P4-02: Robust z-score composite per liquidity bucket

- **Phase:** P4
- **Model:** sonnet
- **Deps:** P2-05
- **Size:** ~110 lines

## Goal
The second detector in PLAN.md 3.3: score each stock each day by how extreme its features are against stocks in the same liquidity bucket that day, then average those robust z-scores into one composite.

## Files
- `src/saham_gorengan/detectors/composite.py` (new)
- `tests/test_detectors_composite.py` (new)

## Interface
```python
DEFAULT_COMPONENTS: tuple[str, ...] = ("ret_norm", "vol_z", "car_5", "runup_20")

def composite_scores(features: pd.DataFrame, components: Sequence[str] = DEFAULT_COMPONENTS,
                     min_group: int = 5, min_components: int = 2) -> pd.DataFrame: ...
    """Input: date, ticker, liq_bucket and the component columns (others ignored).
    Output: date, ticker, z_<component> for each component, score (float64), rank (Int64)."""
```

## Behaviour
- The input is a feature frame, such as the output of P2-08. Missing columns raise `ValueError`; duplicate (date, ticker) rows raise `ValueError`; an empty `components` raises `ValueError`.
- For each date and `liq_bucket` group, and each component: `z = (x - median) / (1.4826 * MAD)` across the group's non-NaN values. z is NaN when the group has fewer than `min_group` non-NaN values, when MAD is 0, or when x is NaN. Rows with NA `liq_bucket` get NaN for every z.
- `score` is the mean of the row's non-NaN z values, or NaN if fewer than `min_components` are available.
- `rank`: per date, 1 = highest score, ties broken by ticker in ascending order, no gaps, NA where score is NaN. This is the same ranking rule as `baselines.py`; reuse its helper if it can be imported cleanly.
- Output is sorted by (date, ticker) with a fresh RangeIndex; dtypes are float64 for z and score, Int64 for rank. The input is not modified.
- No look-ahead: row D uses only rows dated D (the same-day cross-section).

## Acceptance
`tests/test_detectors_composite.py`:
- `test_hand_z`: one date, one bucket, five tickers with `ret_norm` 0, 0.1, 0.2, 0.3, 1.0 give `z_ret_norm` ≈ -1.349, -0.6745, 0, 0.6745, 5.3959 (median 0.2, MAD 0.1).
- `test_buckets_separate`: two buckets with different scales; each ticker's z depends only on its own bucket. Moving one ticker's value in bucket 1 leaves bucket 2's z unchanged.
- `test_min_group`: a bucket with 4 tickers gives NaN z with the default `min_group=5`.
- `test_score_and_rank`: with two components where one is NaN for a ticker, that ticker's score is NaN when `min_components=2` and equals its single z when `min_components=1`. Ranks order by score descending.
- `test_na_bucket`: a row with NA `liq_bucket` gets NaN everywhere and NA rank.
- `test_bad_input`: a missing component column, a duplicate row and `components=()` each raise.
- `test_input_not_modified`.
