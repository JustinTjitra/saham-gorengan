# P5-07: Report recall by price-limit regime

- **Phase:** P5
- **Model:** sonnet
- **Deps:** P5-05
- **Size:** ~90 lines

## Goal
PLAN.md 3.4 requires results to be shown separately for the 2020-2023 ARB 7% regime and for other periods. In the ARB 7% regime, the lower limit censors dumps and limit-down runs dominate, so a detector can look good or bad there for reasons unrelated to pumps. This chunk adds that split to the report. A split by board waits for a board-membership table (PLANNER_NOTES known risk).

## Behaviour
- `window_strata`: for each window, look up `price_limits(start.date(), 1000.0, "regular")`. Use "ARB 7%" when `arb_pct == 7`, "other" for any other result, and "unknown" when `price_limits` raises `ValueError` (a date before the first regime in the data). Duplicate window_ids raise `ValueError`.
- When `strata` is given, `render_report` inserts a section after the per-case table and before the closing note:
  - a `## Recall by price-limit regime` heading;
  - a table with one row per detector and one column per stratum present among the case windows, in the order "ARB 7%", "other", "unknown";
  - each cell is `recall_at_k` over that stratum's case windows, formatted as `0.67 (n=3)`, where n counts windows with n_days > 0. Show `n/a (n=0)` when there are none.
- A window_id in the case metrics that is missing from `strata` raises `ValueError`.
- Placebo and random numbers are not stratified in this chunk.
