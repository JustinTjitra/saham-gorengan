# P3-01: Ticker-day label panel

- **Phase:** P3
- **Model:** sonnet
- **Deps:** P1-01
- **Size:** ~110 lines

## Goal
Turn `data/windows.csv` into one label per (date, ticker) row of a bars panel, with the same class, precision and confidence filters as `labels_on()`. Evaluation (Phase 5) joins detector scores onto this panel.

## Files
- `src/saham_gorengan/labels.py` (new)
- `tests/test_labels_panel.py` (new)

## Interface
```python
def label_panel(bars: pd.DataFrame, classes: Iterable[str] = ("sanctioned", "convicted"),
                precisions: Iterable[str] = ("day", "month", "year"),
                min_confidence: str = "C") -> pd.DataFrame: ...
    """Columns: date, ticker, label ("boolean", never NA), n_windows (Int64), window_id (string),
    label_class (string), confidence (string). Same rows and order as validate_bars(bars)."""
```

## Behaviour
- Call `validate_bars` first and never modify the input.
- Validate `classes`, `precisions` and `min_confidence` exactly as `labels_on()` in `_query.py` does, and raise the same `ValueError`s. Reuse its validation if it can be imported cleanly; otherwise duplicate the checks.
- A window covers (date, ticker) when the tickers match and `start <= date <= end` (inclusive), after the filters are applied.
- `label` is True when at least one window covers the row. `n_windows` is the number of covering windows (0 when none).
- When several windows cover a row, `window_id`, `label_class` and `confidence` come from the window with the best confidence, then the earliest `start`, then the smallest `window_id`. They are NA when `label` is False.
- Use the cached window loader in `_load.py`; don't re-read the CSV.
- This is a label, not a feature: it may use the whole windows table. Say so in the module docstring, so nobody feeds it to a detector.

## Acceptance
`tests/test_labels_panel.py`, using real tickers from `data/windows.csv` in small hand-built bars frames:
- `test_convicted_in_default`: a SWAT row on 2018-06-20 is labelled, with `label_class` "convicted", `confidence` "B" and `window_id` "SWAT-2018-1".
- `test_alleged_off_by_default`: a BEBS row on 2021-06-01 is False by default and True with `classes={"alleged"}`.
- `test_bounds_inclusive`: SWAT rows on 2018-06-08 and 2018-07-05 are True; rows on 2018-06-07 and 2018-07-06 are False.
- `test_precision_filter`: the BEBS row with `classes={"alleged"}, precisions={"day"}` is False (its window is year precision).
- `test_min_confidence`: the SWAT row with `min_confidence="A"` is False.
- `test_unknown_ticker_false`: a ticker with no windows gives `label` False, `n_windows` 0 and NA details.
- `test_bad_filters_raise`: an unknown class, an unknown precision and `min_confidence="Z"` each raise `ValueError`.
- `test_input_not_modified`.

## Out of scope
Weak labels (P3-02 onwards); placebo windows (P5-01b); lead windows before `start` (evaluation handles those).
