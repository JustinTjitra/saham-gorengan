# P4-06: Rank ensemble

- **Phase:** P4
- **Model:** sonnet
- **Deps:** P4-01, P4-02, P4-03
- **Size:** ~90 lines

## Goal
The last step of PLAN.md 3.3: combine the detectors that survive evaluation into one daily ranking by averaging their normalised ranks.

## Files
- `src/saham_gorengan/detectors/ensemble.py` (new)
- `tests/test_detectors_ensemble.py` (new)

## Interface
```python
def ensemble_scores(ranks: Mapping[str, pd.DataFrame], min_detectors: int = 2) -> pd.DataFrame: ...
    """ranks: detector name -> frame with date, ticker, rank (Int64; NA = unranked).
    Output: date, ticker, n_detectors (Int64), ens_score (float64), rank (Int64)."""
```

## Behaviour
- For each detector and date, the normalised rank is `rank / n_ranked`, where `n_ranked` is that detector's count of non-NA ranks on that date. It lies in (0, 1], and lower means more suspicious.
- Rows are the union of (date, ticker) across all inputs. `n_detectors` counts the detectors with a non-NA rank for the row.
- `ens_score` is the mean normalised rank over those detectors, or NaN when `n_detectors < min_detectors`.
- `rank`: per date, ascending `ens_score` (1 = most suspicious), ties broken by ticker in ascending order, NA where NaN. Reuse `baselines._rank` by ranking `-ens_score`, or use an equivalent with identical tie rules.
- An empty mapping raises `ValueError`; so do a frame missing columns or with duplicate (date, ticker) rows (naming the detector), and `min_detectors` that is not an int ≥ 1 (bool rejected).
- Output is sorted by (date, ticker) with a fresh RangeIndex. Inputs are not modified.

## Acceptance
`tests/test_detectors_ensemble.py`, on one date:
- `test_hand_example`: detector A ranks AAAA 1, BBBB 2, CCCC 3, DDDD 4 (normalised 0.25, 0.5, 0.75, 1.0). Detector B ranks AAAA 2 and BBBB 1, with CCCC and DDDD NA (normalised 1.0, 0.5). With `min_detectors=2`: AAAA 0.625, BBBB 0.5, and CCCC and DDDD NaN. The ranks are BBBB 1, AAAA 2, CCCC NA, DDDD NA.
- `test_min_detectors_one`: the same input with `min_detectors=1` gives CCCC 0.75 and DDDD 1.0, ranked 3 and 4.
- `test_union_rows`: a ticker present only in B still appears in the output.
- `test_bad_input`: an empty mapping, a missing column, a duplicate row and `min_detectors=0` each raise.
- `test_inputs_not_modified`.

## Out of scope
Choosing which detectors survive (that is an evaluation decision); weighting detectors.
