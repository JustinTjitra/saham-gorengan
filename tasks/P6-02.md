# P6-02: Watchlist writer with explanations and wording rules

- **Phase:** P6
- **Model:** sonnet
- **Deps:** P6-01
- **Size:** ~130 lines

## Goal
Turn a day's top-k scores into a watchlist record. Each row names the features that drove it, in neutral wording. The record is written to the private data store, never to this repo (PLAN.md 3.5, Q4).

## Files
- `src/saham_gorengan/watchlist.py` (new)
- `tests/test_watchlist.py` (new)

## Interface
```python
DISCLAIMER: str  # one sentence, see Behaviour

def explain(features_row: pd.Series, composite_row: pd.Series, top_n: int = 3) -> str: ...
    """Neutral sentence listing the top_n z-components with the largest absolute value."""

def build_watchlist(day: date, features: pd.DataFrame, composite: pd.DataFrame, k: int = 25) -> pd.DataFrame: ...
    """Columns date, ticker, rank (Int64), score (float64), drivers (string). Rows with rank <= k on `day`, sorted by rank."""

def write_watchlist(df: pd.DataFrame, root: str | Path | None = None) -> Path: ...
    """Writes <store_root(root)>/watchlist/YYYY/YYYY-MM-DD.parquet atomically and returns the path."""
```

## Behaviour
- `explain` uses the `z_<component>` columns of the composite row. It takes the `top_n` with the largest absolute value, skipping NaN, ties broken by component name. Output looks like `"vol_z +4.1, cumret_20 +2.3, ret_norm +1.9"`: the component name without `z_`, a signed value with 1 decimal, joined by `, `. With no non-NaN components it returns `"no components available"`.
- `build_watchlist`: when `composite` has no rows dated `day`, it raises `ValueError("no scores for <day>")`. It raises `ValueError` for k < 1. Tickers stay as given (codes, not company names).
- `DISCLAIMER` = `"Statistical anomaly ranking only; it does not state or imply that any party manipulated a stock."`. `write_watchlist` stores it in the Parquet file's key-value metadata under `disclaimer`.
- Wording guard: `build_watchlist` raises `ValueError` if any `drivers` text contains, case-insensitively, `manipul`, `goreng`, `fraud`, `pump` or `scam`. With the format above this cannot happen; the guard protects future edits.
- `write_watchlist` resolves the root with `store.store_root(root)`. That already raises `RuntimeError` for a path inside this git repository (except the git-ignored `store/` folder) and when no root or `SAHAM_DATA_DIR` is given, which keeps watchlists out of the public repo. It writes to a temp file and renames, like `write_bars`.
- No network access.

## Acceptance
- `test_explain_format`: z values vol_z 4.12, cumret_20 -2.34, ret_norm 1.86, amihud_20 NaN, with top_n=3, give `"vol_z +4.1, cumret_20 -2.3, ret_norm +1.9"`.
- `test_explain_no_components`: all NaN gives `"no components available"`.
- `test_build_watchlist`: on a synthetic panel with one strong default `Pump` (as in the P6-01 tests), the pump ticker is in the top 3 and `drivers` is non-empty for every row.
- `test_wording_guard`: monkeypatch `explain` to return `"pump detected"`; `build_watchlist` raises.
- `test_write_roundtrip`: `write_watchlist` to `tmp_path` gives the dated path, the file reads back equal, and the metadata holds the disclaimer.
- `test_refuses_repo_root`: a root inside the repo, such as its `docs/` folder, raises `RuntimeError`.
- `test_missing_day` and `test_bad_k`.
