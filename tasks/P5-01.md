# P5-01: Event-level recall, share-in-top-k and lead-time metrics

- **Phase:** P5
- **Model:** sonnet
- **Deps:** P3-01, P4-01
- **Size:** ~140 lines

## Goal
The evaluation metrics of PLAN.md 3.4: for each labelled window, did the stock enter the daily top-k, what share of the window's days it spent there, and how early it was first flagged.

## Files
- `src/saham_gorengan/evaluation/__init__.py` (new; docstring only)
- `src/saham_gorengan/evaluation/metrics.py` (new)
- `tests/test_evaluation_metrics.py` (new)

## Interface
```python
def window_metrics(ranks: pd.DataFrame, windows: pd.DataFrame, k: int = 25, lead: int = 20) -> pd.DataFrame: ...
    """ranks: columns date, ticker, rank (Int64; NA = unranked). windows: columns window_id, ticker, start, end.
    Output, one row per window: window_id, ticker, n_days (Int64), found ("boolean"), share_in_topk (float64),
    first_flag_offset (Int64)."""

def recall_at_k(metrics: pd.DataFrame) -> float: ...
    """Share of windows with found True, over windows with n_days > 0. NaN if there are none."""
```

## Behaviour
- **Trading days** are the sorted unique dates in `ranks`.
- **Window days** are the trading days in [start, end], inclusive. `n_days` is how many of those days the window's ticker has a row in `ranks`.
- **Search span:** the `lead` trading days before `start` (or as many as exist), plus the window days.
- `found` is True if the ticker has `rank <= k` on any trading day in the search span.
- `share_in_topk`: the share of the window's days with a ranks row where `rank <= k`. NaN when `n_days` is 0.
- `first_flag_offset`: the number of trading days from `start` to the first day in the search span with `rank <= k`. It is negative when that day is before `start`, 0 on the first trading day on or after `start`, and NA when not found.
- A window whose ticker never appears in `ranks` gets `n_days` 0, `found` False, NaN share and NA offset.
- `k` and `lead` are ints (bool not allowed), with `k >= 1` and `lead >= 0`; otherwise raise `ValueError`. Missing columns raise `ValueError`.
- Output is ordered as `windows`, with a fresh RangeIndex; neither input is modified.

## Acceptance
`tests/test_evaluation_metrics.py`, with 30 business days from 2024-01-01 and ticker AAAA ranked on every day:
- `test_found_inside_window`: the window spans days 11-20; AAAA has rank 30 everywhere except rank 3 on days 15 and 16. With `k=25, lead=5`: `found` True, `n_days` 10, `share_in_topk` 0.2, `first_flag_offset` 4.
- `test_found_in_lead`: the same, but rank 3 only on day 8 (before `start`). With `lead=5`, `found` is True and `first_flag_offset` is -3. With `lead=2`, `found` is False.
- `test_not_found`: rank 30 everywhere gives `found` False and `share_in_topk` 0.0.
- `test_missing_ticker`: a window for BBBB, which has no ranks, gives `n_days` 0, False, NaN and NA.
- `test_recall`: three windows (found, not found, missing ticker) give `recall_at_k` 0.5.
- `test_bad_args`: `k=0`, `lead=-1`, `k=True` and a missing `rank` column each raise.
- `test_inputs_not_modified`.
