# P0-05: Market events table

- **Phase:** P0
- **Model:** haiku
- **Deps:** none
- **Size:** ~120 lines

## Goal
A dated table of market-wide trading halts and structural breaks, so that features and evaluation can mask or stratify those days.

## Files
- `data/market_events.csv` (new)
- `src/saham_gorengan/events.py` (new)
- `src/saham_gorengan/__init__.py` (exports)
- `tests/test_events.py` (new)

## Interface
CSV header, exactly:
```
date,event_type,scope,description,confidence,source_url,notes
```
- `event_type` is one of `trading_halt`, `structural_break` or `rule_change`.
- `scope` is one of `market`, `regular_board`, `watchlist_board` or `all_boards`.
- `confidence` is A, B or C. Use C when only one outlet or a search snippet supports the row, and say "unconfirmed" in the notes if the research says so.

```python
@dataclass(frozen=True)
class MarketEvent:
    date: date
    event_type: str
    scope: str
    description: str
    confidence: str
    source_url: str
    notes: str

def load_market_events() -> list[MarketEvent]: ...
def events_between(start: date, end: date, types: Iterable[str] | None = None) -> list[MarketEvent]: ...  # inclusive, sorted by date
```

## Behaviour
Copy the rows from `research_notes/IDX manipulation detector sources/trading_rules_history.md`:
- **Section 7, every market-wide trading halt listed:**
  - 2020: 03-13, 03-17, 03-19, 03-23, 03-30 and 09-10, plus 03-12 marked unconfirmed;
  - 2025: 03-18 and 04-08;
  - 2026: 01-28, 01-29 and 10-16.
- **Structural breaks and rule changes it names:**
  - 2020-03-13: pre-opening suspended, IPO limit cut to 1x;
  - 2021-12-06: broker codes hidden, random closing;
  - 2024-03-25: watchlist full call auction;
  - 2026-09-15: short selling starts;
  - 2026-09-28: Rp50 floor removed, 92 stocks leave the watchlist board;
  - 2026-10-19: ARB cut to 7%.

Take each source URL from the notes. Do not add events the notes don't contain. Invalid enum values raise `ValueError` naming the row.
