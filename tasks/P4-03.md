## Goal
The third detector in PLAN.md 3.3: an isolation forest fitted per liquidity bucket on a trailing window and refitted walk-forward, so a score for day D never uses data from D or later in training. This chunk adds scikit-learn, as PLAN.md 6 foresees.

## Interface
```python
def iforest_scores(features: pd.DataFrame, components: Sequence[str] = DEFAULT_COMPONENTS,
                   train_days: int = 250, refit_every: int = 20, min_train: int = 200,
                   seed: int = 0) -> pd.DataFrame: ...
    """Input like composite_scores (date, ticker, liq_bucket, components). Output: date, ticker, score (float64), rank (Int64)."""
```
`DEFAULT_COMPONENTS` is imported from `detectors/composite.py`.

## Behaviour
- Trading days are the sorted unique dates. Refit dates are every `refit_every`-th trading day, starting at index `train_days`. Rows before the first refit date get NaN scores.
- At each refit date d, for each `liq_bucket` value, fit `sklearn.ensemble.IsolationForest(n_estimators=100, random_state=seed)`. Train on rows of that bucket with dates in the `train_days` trading days **strictly before d**, keeping only rows where all components are non-NaN. Skip a bucket with fewer than `min_train` rows.
- Score the rows of that bucket from d up to, but not including, the next refit date: `score = -model.score_samples(X)`, so higher means more anomalous. Rows with any NaN component, NA bucket or no fitted model get NaN.
- `rank`: per date by score descending, ties by ticker in ascending order, NA where NaN. Reuse `baselines._rank`.
- Validation as in `composite_scores`: missing columns, duplicates and empty components raise `ValueError`. Int args must be ints ≥ 1 (bool rejected). The input is not modified. Output is sorted by (date, ticker) with a fresh RangeIndex.

## Acceptance
`tests/test_detectors_iforest.py`:
- `test_outlier_scores_highest`: one bucket, 30 tickers, 300 days of N(0, 1) components (seeded). On day 290 one ticker gets values of +8 in every component. That row has rank 1 on its date.
- `test_training_strictly_before`: monkeypatch `IsolationForest.fit` to record the max date of each training set together with its refit date. Every training max date is earlier than its refit date.
- `test_warmup_nan`: rows before trading day `train_days` have NaN score and NA rank.
- `test_min_train_skips_bucket`: a bucket with too few rows gets NaN scores; another bucket still scores.
- `test_deterministic`: the same seed gives identical scores.
- `test_bad_input`: a missing column and `train_days=0` raise.
- Runtime: the whole test file finishes in under 60 seconds.
